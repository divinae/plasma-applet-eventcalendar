Event Calendar NG

Privacy Policy

Last updated: 2026-11-05

In short

Event Calendar NG is a widget that runs on your computer. It connects only to the services you set up in it, directly from your computer: there are no servers of the developer in between, and it collects no usage data or analytics. Sign-ins and passwords are kept in your system keyring (KWallet or the Secret Service), not in the widget's settings.

Downloads

Installed from the KDE panel or store.kde.org, the widget comes from the KDE Store (its privacy policy); from a release or the source, from GitHub (its privacy statement). The developer sees how many times each release was downloaded, not who downloaded it.

Google Calendar and Google Tasks

The widget connects to Google only after you sign in from its settings. Signing in opens Google's own page in your browser; the widget then reads your calendars, events, task lists and tasks from the Google Calendar and Google Tasks APIs to show them, and changes events and tasks only when you edit them in the widget. It refreshes them now and then while it runs.

The sign-in (access and refresh tokens) is kept in your system keyring. The widget's settings keep your account's name and which calendars and task lists to show.

Google's API console shows the owner of the sign-in client (the one built into the widget, or your own if you set one up) the number of requests and errors per API method, summed over all users: no personal data and no per-user figures.

CalDAV, KDE PIM and .ics calendars

A CalDAV account (Nextcloud, Fastmail, iCloud…) is read and changed directly on the server you enter; its password is kept in your system keyring. Calendars of KDE PIM (Akonadi) are read through Plasma's own calendar plugin, on your computer. An .ics link is downloaded from the address you enter; a local .ics file is read from the widget's own folder only.

TickTick

With a TickTick account added, the widget reads and changes your TickTick tasks through its API; the sign-in is kept in your system keyring.

Weather

The widget asks for a forecast only once you set a location, from the service you choose: Open-Meteo (the coordinates of the place you picked), OpenWeatherMap (the city) or Weather Canada (the city). That service sees the place and your IP address.

On your computer

  • Offline start: the last loaded events and tasks (no descriptions or notes) are kept in ~/.cache/plasma-eventcalendar to show them before the first refresh. Settings > General > Offline turns it off and deletes the copy.
  • Python modules: for CalDAV and .ics calendars the widget can install the icalendar and recurring-ical-events modules from the Python Package Index (PyPI) when you click Install.
  • Sharing with Glance (off by default): today's and tomorrow's events and the weather are sent to the Glance panel widget over D-Bus, on this computer only; no descriptions or guests' addresses.
  • Settings backup: an exported settings file contains no passwords or sign-ins.

This website

These pages are hosted on GitHub Pages (GitHub's privacy statement). The sign-in helper on the home page runs only in your browser: the address you paste is read there and sent nowhere.
