# Maintenance Status

This is a maintained fork of Event Calendar (originally by Chris Holland / Zren,
later ALikesToCode) for KDE Plasma 6.

Development happens on `master`; releases are tagged from it.

Plasma 5 is not supported.

My personal time is limited, so I may not be able to address non critical
issues quickly. If you can help, please open a pull request. Even small fixes
and documentation updates are appreciated.
